Privacy Policy

Last updated: October 12, 2026

Who uses this app

Shorts Uploader (숏츠 업로더) is a private, single-user tool. It is used only by the owner of the YouTube channels 「그때 당신이라면」 and 「You Choose History」 to upload that owner's own videos. It is not offered to the public.

What data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to:

  • upload videos and set their title, description, tags and privacy status;
  • read the authorized channel's ID and name to confirm the correct channel;
  • create playlists and add the uploaded videos to them.

The app does not access any other Google data, and does not read viewers' personal information.

How data is stored

The OAuth access token is stored only on the owner's own computer. No data is sent to any server other than Google's. No data is sold, shared with third parties, or used for advertising.

How to revoke access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.
